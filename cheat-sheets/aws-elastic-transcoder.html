AWS Elastic Transcoder

AWS Cheat Sheet

Amazon Elastic Transcoder 是一种高度可扩展、易用且经济高效的方式，让开发者和企业能够将视频和音频文件从源格式转换（即“转码”）为可在智能手机、平板电脑和 PC 等设备上播放的版本。

支持广泛的输入和输出格式、分辨率、码率和帧率。

还提供视频码率自动优化、缩略图生成、可视水印叠加、字幕支持、DRM 打包、渐进式下载、加密等功能。

从输入 S3 bucket 读取文件，并将输出保存到输出 S3 bucket。

使用 JSON API，并提供 Python、Node.js、Java、.NET、PHP 和 Ruby 的 SDK。

为常见格式提供转码预设（preset）。

按内容时长以及媒体的分辨率或格式计费。
